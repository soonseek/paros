# PRD - 법무법인 파로스 파산 사건 분석 시스템

## 문제 정의
법무법인 파로스의 파산 사건 처리를 위한 전문 분석 도구. 거래내역서를 업로드하면 AI가 자동으로 분석하여 이상 거래를 탐지하고, 법률 전문가의 업무 효율을 극대화.

## 아키텍처
- **프론트엔드**: Next.js 15.5.9 (Pages Router) + Tailwind CSS + shadcn/ui
- **백엔드**: tRPC + Prisma ORM
- **데이터베이스**: PostgreSQL
- **AI**: Upstage Solar / OpenAI GPT / Anthropic Claude

## 사용자 페르소나
1. **변호사 (LAWYER)**: 파산 사건 담당 변호사
2. **법무사 (PARALEGAL)**: 법무사 지원 인력
3. **관리자 (ADMIN)**: 시스템 관리자
4. **지원팀 (SUPPORT)**: 기술 지원 인력
